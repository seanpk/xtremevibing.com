# xtremevibing.com

Public pages for Xtreme Vibing (XV): Sean Kennedy's notes on carrying Extreme Programming into
agent-written software. Three pages: summary, map, and the delivery loop. Eleventy 3, deployed as a
Cloudflare Worker with static assets.

## Generated content

`index.md`, `map.md` and `loop.md` are generated by `bin/publish-site.py` in the private
xtreme-vibing repo and copied here. Do not edit them in this repo; the next publish overwrites them.
Their front matter (`title`, `description`, `updated`, `permalink`, `nav`, `order`, and `mermaid`
for the loop page) drives the nav and the meta tags. Everything else here is hand-written.

## Develop

Node 24 (`.nvmrc`).

```
npm install
npm run build     # clean, eleventy, then scripts/check-page.js
npm run serve     # eleventy dev server
npm run preview   # build, then wrangler dev
npm run og        # regenerate static/og.png (needs Playwright's Chromium)
```

## Deployment

Four hostnames point at one Worker, `xtremevibing-com`: `xtremevibing.com`, `www.xtremevibing.com`,
`extremevibing.com` and `www.extremevibing.com`. They are Custom Domains, attached in Cloudflare and
named in `wrangler.toml`. `src/index.js` runs on every request and sends any host other than the apex
to the same path on `https://xtremevibing.com`; the apex serves `_site`.

**A push to `master` publishes.** `.github/workflows/deploy.yml` builds the site and runs
`npx wrangler deploy` with two repository secrets: `CLOUDFLARE_API_TOKEN` (a token that can edit
Workers in the account that holds the zones) and `CLOUDFLARE_ACCOUNT_ID`. Cloudflare's own Workers
Builds is not used, because that GitHub app is tied to a different Cloudflare account for this
GitHub user. The same two commands work from a machine where `npx wrangler login` has been run:

```
npm run build
npx wrangler deploy
```
