# xtremevibing.com

Public pages for Xtreme Vibing (XV): Sean Kennedy's notes on carrying Extreme Programming into
agent-written software. Three pages: summary, map, and the delivery loop. Eleventy 3, deployed as a
Cloudflare Worker with static assets.

## Generated content

`index.md`, `map.md` and `loop.md` are generated by `bin/publish-site.py` in the private
xtreme-vibing repo and copied here. Do not edit them in this repo; the next publish overwrites them.
Their front matter (`title`, `description`, `updated`, `permalink`, `nav`, `order`, and `mermaid`
for the loop page) drives the nav and the meta tags. Everything else here is hand-written.

## Develop

Node 24 (`.nvmrc`).

```
npm install
npm run build     # clean, eleventy, then scripts/check-page.js
npm run serve     # eleventy dev server
npm run preview   # build, then wrangler dev
npm run og        # regenerate static/og.png (needs Playwright's Chromium)
```

## Deployment

Four hostnames point at one Worker: `xtremevibing.com`, `www.xtremevibing.com`, `extremevibing.com`
and `www.extremevibing.com`. They are Custom Domains in `wrangler.toml`, so `npx wrangler deploy`
creates their DNS records. `src/index.js` runs on every request and sends any host other than the
apex to the same path on `https://xtremevibing.com`; the apex serves `_site`.

First deploy, from a machine where `npx wrangler login` has been run:

```
npm run build
npx wrangler deploy
```

After that, connect this repo to Cloudflare Workers Builds so a push to `master` publishes: build
command `npm run build`, deploy command `npx wrangler deploy`. The Worker name must match `name` in
`wrangler.toml` (`xtremevibing-com`). `wrangler.toml` has no account id on purpose.
